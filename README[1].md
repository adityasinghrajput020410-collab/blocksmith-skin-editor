# Blocksmith Skin Editor

Paint Minecraft skins in the browser: on the flat 64×64 skin or directly on the 3D model. One HTML file, no backend, works on GitHub Pages / Vercel.

- Tools: pencil, eraser, face fill, colour picker, lighten, darken; brush 1-4; opacity; recent colours
- Mirror left/right (works across arms and legs, on both views)
- Base / overlay layers (hat, jacket, sleeves, pants), show/hide each
- Classic and slim arms, undo/redo (100 steps), autosave in your browser
- Import any 64×64 or old 64×32 skin PNG (old ones are converted), export a clean 64×64 PNG
- Keys: B E G I L D tools, 1-4 brush, M mirror, Ctrl+Z / Ctrl+Y

Deploy: upload `index.html` to a repo and enable Pages. Nothing to configure.

Pair it with the Blocksmith Skin Host to get a link for SkinsRestorer.
